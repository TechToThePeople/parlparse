# <a title of at most 12 words>

Only when the title above is not already the one you would write. If it is — or if
the title above is empty — leave this line out entirely and start with the
description: never restate the title we gave you.

## <the description, 60 to 90 words>

The line starts with "## " — it is a heading, and everything after the two hashes is
the description itself. One paragraph, plain prose, on what it changes or asks for. It is used as
the page description, so it has to stand alone: no "this text", no reference to
the title, no "as mentioned above". Start with the substance ("Broadcasters in
Czechia would…", "MEPs ask the Czech government…", "National rules would…").

Then three bullet points of at most 20 words each: what concretely changes, who it
affects, what happens next.

Do not invent facts that are not in the text. If it only gives an opinion, say so
plainly.
